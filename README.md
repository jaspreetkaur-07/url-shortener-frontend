# URL Shortener - Frontend

A clean, modern React app to shorten URLs, built to work with the Spring Boot backend.

## Features
- Simple, elegant UI to paste and shorten URLs
- Copy short URL with one click
- Real-time feedback with loading and error states

## Tech Stack
- React
- Vite
- Tailwind CSS

## How to Run
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:5173`

**Note:** Requires the backend to be running at `http://localhost:8080`
